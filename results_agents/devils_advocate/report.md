# Агент-скептик: попытка развалить основной вывод

**Задача.** Проверить, не является ли заявленный вывод
(PL `d_min=2`: `λ₂(giant) ~ n^(−0.15…0.17)`, R²≈1.0; `d_min=3`: α≈0.03;
ER: α≈0.09–0.14; *«power-law даёт α ~2× больше ER при близкой средней степени
2-core»*) методологическим артефактом.

**Метод.** Только существующие CSV (`results_merged`, `results_er`, `results_toy`)
+ сохранённые графы `results_v2/graphs/*.npz`. Код и данные проекта не изменялись.
Скрипты и полные числа: `analyze.py`, `analyze2.py`, `analyze3.py`,
`solver_check.py`, `report_data*.txt` (эта папка).

**Как считался α.** Как в проекте: среднее `λ₂` по реализациям внутри каждого
`n_target`, затем МНК `log λ₂` vs `log n` по 8 точкам.

## 3–5 самых опасных пунктов

1. **(#5/#6) Сравнение «PL giant 0.15–0.17 vs ER 0.09–0.14» — склейка разных
   объектов.** PL-число — это `λ₂(giant)` (совпадает с core из-за frac_2core≈0.99),
   а ER-число 0.09–0.14 — это `λ₂(core)`. Корректное сравнение:
   - на **giant** PL 0.15–0.17 **меньше** ER 0.17–0.27 → power-law затухает
     *медленнее*, а не в 2× быстрее;
   - на **2-core** при близком core-d̄ отношение действительно ≈1.5–2.1.
   Заголовок «power-law в ~2× быстрее ER» держится только на core-vs-core и
   обрушивается при сравнении заявленных `λ₂(giant)`.

2. **(#11) Каузальный вывод «тяжёлый хвост ускоряет спад» конфаундирован долей
   degree-2.** Переход d2→d3 (α 0.15→0.03) совпадает с падением N2/n с 0.43–0.62
   до 0.003–0.004. Эффект может быть про цепочки степени 2, а не про хвост;
   toy-контроли частично это подтверждают (uniform{2..D}: α≈0.06–0.07 плоско,
   PL{2..D}: 0.10–0.16), но однозначно разделить хвост и degree-2 на этих данных
   нельзя.

3. **(#10) λ₂(giant) — локализованный дефект, а не глобальная щель.** IPR₂·n
   растёт почти линейно с n (≈const IPR₂≈0.1–0.17, носитель ~6–10 вершин;
   прямой dense-пересчёт подтверждает локализацию на цепочке degree-2). Значит,
   фитируется экстремальная О(1)-структура; её степенной спад может быть
   конечноразмерным/extreme-value эффектом, которому не обязано быть места в
   асимптотике.

4. **(#7/#8) «R²≈1.0, чистый степенной закон» переоценено.** R²≈1.0 получен
   усреднением по реализациям (pooled R²=0.51–0.80). AICc для d2 γ3.0 и d3 γ2.5/3.0
   выбирает `A·exp(−c(log n)^β)` (β≈0.5), т.е. закон **не однозначно степенной**.

5. **(#4/#9) α чувствительна к диапазону и к росту поддержки степеней.**
   При n≥10⁴ α(pl_dmin2 γ2.5) падает 0.158→0.135; d_max_obs растёт с n (17–27→50)
   и насыщается лишь к n≈3·10⁴, а toy-контроль показывает рост α с поддержкой D.
   Часть измеренного α может быть конечномерным дрейфом.

## Переживёт ли основной вывод проверки?

- **Численный факт** «α(pl_dmin2 giant) ≈ 0.15–0.17 на n=100…10⁵, α(pl_dmin3)
  ≈ 0.03» — **в основном переживает**: джиттер n, смена решателя и слияние
  источников опровергнуты; α устойчива в пределах ±0.02 (частично ±0.023 при
  урезании диапазона).
- **Сравнительный вывод** «power-law даёт α ~2× ER при близкой степени 2-core» —
  **не переживает** как сформулирован: это артефакт сравнения PL-giant с ER-core;
  на giant relation обратное.
- **Каузальный вывод** «усиление из-за тяжёлого хвоста» — **не переживает**:
  конфаунд с долей degree-2 и с ростом поддержки; локализация λ₂ на О(1)-дефекте
  делает асимптотическую интерпретацию сомнительной.
